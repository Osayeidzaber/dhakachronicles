# Instagram setup (@dhakachronicles)

The integration uses only Meta's official **Instagram API with Unified Login** (`graph.facebook.com`, Graph API v27.0). This is the setup Meta gives new apps; "API setup with Instagram login" is no longer available for them. There is no scraping and no unofficial API. Until the steps below are done, the admin Instagram page shows "not configured" and nothing is imported.

## Done in code

- OAuth through the Facebook Login for Business dialog, using the Unified Login **configuration ID** (no `scope` parameter; the configuration defines permissions). A single-use CSRF `state` is bound to the admin who started it.
- The code is exchanged for a **Business Integration System User access token** (default: never expires). It is stored **AES-256-GCM encrypted** in `instagram_tokens`. That table has no RLS policies, so only the service role can read it. If a configuration sets an expiry, the account is marked `token_expired` when it passes and asks for a reconnect.
- Every Graph call sends `appsecret_proof` (HMAC of the token with the app secret).
- **Account check:** after login the app reads `/me/assigned_instagram_accounts`. If none of the shared accounts is `INSTAGRAM_EXPECTED_USERNAME` (default `dhakachronicles`), nothing is stored and the admin sees an error. Only that one account is used, even if others were shared.
- Sync paginates `/{ig-user-id}/media` with the fields `id, caption, media_type, media_url, thumbnail_url, permalink, timestamp, children{...}`.
  - Duplicates are detected by `instagram_media_id`, which also has a UNIQUE constraint in the database.
  - Image, carousel (each child image) and video (thumbnail only) posts are supported. Media that can't be downloaded is recorded rather than crashing the sync.
  - Media is downloaded server-side (Instagram/Facebook CDN hosts only), optimized and stored in R2.
  - Each post becomes a **draft** with the caption kept verbatim, plus the permalink and timestamp. Editors are notified.
  - Failed imports retry with backoff (5m, 20m, 80m, 5h20m; at most 5 attempts) and can be retried by hand.
  - Only one sync can run at a time; a sync stuck for more than 30 minutes is released automatically.
- Historical import lets you set the max posts, page size, max pages and a date range.
- Auto-import toggle. Supabase Cron calls `/api/cron/instagram-sync` every 15 minutes.
- Webhook endpoint `/api/instagram/webhook`: answers Meta's verify-token check and acknowledges signed events. It does not act on them.
- Nothing is ever published automatically.

## Manual steps (Meta)

1. **Make @dhakachronicles a Professional account** (Business or Creator) and make sure it belongs to a Meta business portfolio.
2. **Create a Meta app** (Business type) with the Instagram API use case.
3. In **Use cases → Instagram API → API setup with Unified login**:
   - **Configure your app:** create a configuration ("Instagram API (unified login)") that includes the Instagram account and `instagram_basic`. Copy its **Configuration ID** → `INSTAGRAM_CONFIG_ID`.
   - **Redirect URL:** register `https://dhakachronicles.com/api/instagram/callback`. It must match `INSTAGRAM_REDIRECT_URI` exactly.
   - **Webhooks (if Meta requires it):** callback `https://dhakachronicles.com/api/instagram/webhook`, verify token = `INSTAGRAM_WEBHOOK_VERIFY_TOKEN`.
4. **App ID and secret:** App settings → Basic → **App ID** → `INSTAGRAM_APP_ID`, **App secret** → `INSTAGRAM_APP_SECRET`.
5. **Access level:** while the app is in Development mode, people who log in must have a role on the app (for example Instagram Tester, accepted from Instagram → Settings → Website permissions → Apps and websites → Tester invites).
6. **Environment variables:**
   ```
   INSTAGRAM_APP_ID=...
   INSTAGRAM_APP_SECRET=...
   INSTAGRAM_CONFIG_ID=...
   INSTAGRAM_REDIRECT_URI=https://dhakachronicles.com/api/instagram/callback
   INSTAGRAM_EXPECTED_USERNAME=dhakachronicles
   INSTAGRAM_WEBHOOK_VERIFY_TOKEN=...
   TOKEN_ENCRYPTION_KEY=<node -e "console.log(require('crypto').randomBytes(32).toString('base64'))">
   ```
   R2 must also be configured, because imported media is stored there.
7. **Connect:** go to Admin → Instagram → **Connect Instagram**, log in, choose the business portfolio and **@dhakachronicles**, and approve. Then run **Run historical import** and turn on **automatic synchronization** if you want it.

Tokens generated by hand in the Meta dashboard are not used; the app gets its own token through Connect.

## Limits and notes

- Rate limits are counted per account per hour (Meta's BUC limits). Scheduled syncs fetch at most one page of 25 posts. For large historical imports, run several smaller imports.
- Instagram's `media_url` values expire, so the importer downloads media right away during the sync.
- Some media isn't returned by the API (for example, reels with copyrighted audio may have no `media_url`). The draft is still created, without that media.
- The token stops working if the app is removed under Business Settings → Integrations → Connected apps, or the account moves to another portfolio. Reconnect from the admin page.
- Connecting without sharing `dhakachronicles` is refused, and the attempt is written to `audit_logs`.
